# Ch 2 — Packages, custom interfaces, launch files (week 2)

Goal: define the data model of the cell once (`cell_interfaces`) and learn to start many nodes with one command (`cell_bringup`). Everything later imports these types.

## The data model

A box is the unit of work. Its pose is the **center** of the box, in a named frame, with its extents in the box's own axes.

```text
cell_interfaces/
├── msg/Box.msg        msg/BoxArray.msg
├── srv/SpawnBox.srv   srv/GetBoxes.srv   srv/SetSuction.srv
└── action/PickPlace.action   action/RunJob.action
```

```text
# msg/Box.msg
string id                        # unique, e.g. "box_007"
string sku                       # "A", "B" … or a barcode
geometry_msgs/PoseStamped pose   # center of the box; pose.header.frame_id names the frame
geometry_msgs/Vector3 size       # x, y, z extents [m] along the box's own axes
string location                  # "pallet" | "conveyor" | "gripper" | "unknown"
```

```text
# msg/BoxArray.msg
std_msgs/Header header
Box[] boxes
```

```text
# srv/SpawnBox.srv
Box box
---
bool success
string message

# srv/GetBoxes.srv
string location        # "" = all
---
Box[] boxes

# srv/SetSuction.srv
bool on
---
bool success
string message
```

```text
# action/PickPlace.action
string box_id
geometry_msgs/PoseStamped pick_pose    # TCP pose at grasp (Ch 11 explains why TCP, not box)
geometry_msgs/PoseStamped place_pose   # TCP pose at release
geometry_msgs/Vector3 box_size
float64 approach_distance 0.15         # field default
---
bool success
string message
---
string stage                           # APPROACH, DESCEND, GRIP, LIFT, TRANSIT, PLACE, RELEASE, RETREAT

# action/RunJob.action
string mode            # "depalletize" | "palletize"
string strategy        # "single_sku" | "mixed"
int32 max_boxes -1     # -1 = until empty/full
---
bool success
int32 boxes_moved
string message
---
string state
int32 boxes_moved
```

## Build files

```bash
cd ~/pal_ws/src && ros2 pkg create --build-type ament_cmake cell_interfaces
mkdir -p cell_interfaces/{msg,srv,action}   # then create the files above
```

```cmake
# cell_interfaces/CMakeLists.txt
cmake_minimum_required(VERSION 3.8)
project(cell_interfaces)
find_package(ament_cmake REQUIRED)
find_package(rosidl_default_generators REQUIRED)
find_package(std_msgs REQUIRED)
find_package(geometry_msgs REQUIRED)
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/Box.msg" "msg/BoxArray.msg"
  "srv/SpawnBox.srv" "srv/GetBoxes.srv" "srv/SetSuction.srv"
  "action/PickPlace.action" "action/RunJob.action"
  DEPENDENCIES std_msgs geometry_msgs)
ament_export_dependencies(rosidl_default_runtime)
ament_package()
```

```xml
<!-- cell_interfaces/package.xml: add inside <package> -->
<buildtool_depend>rosidl_default_generators</buildtool_depend>
<depend>std_msgs</depend>
<depend>geometry_msgs</depend>
<depend>action_msgs</depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<member_of_group>rosidl_interface_packages</member_of_group>
```

```bash
cd ~/pal_ws && colcon build --packages-select cell_interfaces && source install/setup.bash
ros2 interface show cell_interfaces/action/PickPlace
ros2 interface show cell_interfaces/msg/Box
```

Use from C++: `#include <cell_interfaces/msg/box.hpp>`, `#include <cell_interfaces/srv/set_suction.hpp>`, `#include <cell_interfaces/action/pick_place.hpp>` (a CamelCase interface name becomes a snake_case file name). Packages that use them add `find_package(cell_interfaces REQUIRED)` and `cell_interfaces` in `ament_target_dependencies(...)` to `CMakeLists.txt`, and `<depend>cell_interfaces</depend>` to `package.xml`.

## Launch files

A launch file is Python that builds a tree of actions: nodes, includes, arguments, conditions. That stays true in a C++ workspace: launch files are the one place where Python is the standard even for C++ nodes. Create `cell_bringup` (ament_cmake, no code) and start the Ch 1 nodes from one file.

```python
# cell_bringup/launch/basics.launch.py
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare

def generate_launch_description():
    period = LaunchConfiguration('period_s')
    params = PathJoinSubstitution([FindPackageShare('cell_bringup'), 'config', 'basics.yaml'])
    return LaunchDescription([
        DeclareLaunchArgument('period_s', default_value='1.0'),
        Node(package='ros2_basics', executable='photo_eye', output='screen',
             parameters=[params, {'period_s': period}]),   # later entries override earlier ones
        Node(package='ros2_basics', executable='suction', output='screen'),
        Node(package='ros2_basics', executable='countdown', output='screen'),
    ])
```

```yaml
# cell_bringup/config/basics.yaml
photo_eye:
  ros__parameters:
    period_s: 1.0
```

```cmake
# cell_bringup/CMakeLists.txt (after find_package(ament_cmake REQUIRED))
install(DIRECTORY launch config DESTINATION share/${PROJECT_NAME})
ament_package()
```

```bash
colcon build --symlink-install && source install/setup.bash
ros2 launch cell_bringup basics.launch.py period_s:=0.5
ros2 launch cell_bringup basics.launch.py --show-args
```

Three launch idioms you will use constantly:

| Idiom | Code |
| --- | --- |
| Include another launch file | `IncludeLaunchDescription(PythonLaunchDescriptionSource([FindPackageShare('pkg'), '/launch/x.launch.py']), launch_arguments={'a': 'b'}.items())` |
| Run only if an argument is true | `Node(..., condition=IfCondition(LaunchConfiguration('use_rviz')))` |
| Remap a topic | `Node(..., remappings=[('points', '/camera/points')])` |
