# Ch 4 — TF2: the frames of a robot cell (week 3)

Goal: move poses between `world`, `pallet_frame`, `camera_optical_frame` and `tcp` without guessing signs. Every bug in vision-guided picking that is "off by a few centimeters in a strange direction" is a frame bug.

## Frames in this cell

| Frame | Parent | Moves? | Published by | Used for |
| --- | --- | --- | --- | --- |
| `world` | — | no | — | everything is ultimately expressed here |
| `base_link` | `world` | no | robot_state_publisher (URDF) | MoveIt planning frame |
| `tool0` → `tcp` | wrist_3 | **yes** | robot_state_publisher from `/joint_states` | pick and place poses |
| `pallet_frame` | `world` | no | URDF | box positions as (x, y, z above deck) |
| `conveyor_frame` | `world` | no | URDF | pick/drop point on the belt |
| `camera_optical_frame` | `camera_link` | no | URDF | point cloud data lives here |
| `box_<id>` | `pallet_frame` / `conveyor_frame` | yes | world_model (Ch 8) | debugging, RViz |

## The one rule

`lookupTransform(target, source, time)` returns the pose of `source`'s origin expressed in `target`. Applying it to a point converts the point **from** `source` **to** `target` coordinates.

```text
T_world_tcp = lookupTransform('world', 'tcp')      # where is the TCP, in world
p_world     = T_world_cam · p_cam                   # a point seen by the camera, in world
T_pallet_box = inv(T_world_pallet) · T_world_box    # chain by multiplication
```

Time: `tf2::TimePointZero` means "latest available". A specific stamp fails with *extrapolation into the future* if the listener has not received that transform yet; pass a timeout (`tf2::durationFromSec(0.5)`) to wait.

## Geometry helpers in C++: `cell_planning/include/cell_planning/geometry.hpp`

Create `cell_planning` now as a header-only `ament_cmake` library. It holds math with no node code, so GoogleTest can test it without ROS running. Poses are `Eigen::Isometry3d` (a 4 × 4 rigid transform); `tf2_eigen` converts to and from the message types.

```cpp
#pragma once
#include <cmath>
#include <Eigen/Geometry>
#include <geometry_msgs/msg/pose.hpp>
#include <geometry_msgs/msg/transform.hpp>
#include <tf2_eigen/tf2_eigen.hpp>

namespace cell_planning {

using Eigen::Isometry3d;

inline Isometry3d matFromPose(const geometry_msgs::msg::Pose & p) { Isometry3d T; tf2::fromMsg(p, T); return T; }
inline Isometry3d matFromTf(const geometry_msgs::msg::Transform & t) { return tf2::transformToEigen(t); }
inline geometry_msgs::msg::Pose poseFromMat(const Isometry3d & T) { return tf2::toMsg(T); }

inline Isometry3d trans(double x = 0.0, double y = 0.0, double z = 0.0) { return Isometry3d(Eigen::Translation3d(x, y, z)); }
inline Isometry3d rotX(double a) { return Isometry3d(Eigen::AngleAxisd(a, Eigen::Vector3d::UnitX())); }
inline Isometry3d rotZ(double a) { return Isometry3d(Eigen::AngleAxisd(a, Eigen::Vector3d::UnitZ())); }
inline double yawOf(const Isometry3d & T) { return std::atan2(T(1, 0), T(0, 0)); }

/// TCP pose for a suction grasp: at the box's top-face center, TCP z pointing into the box.
/// tcp z points out of the pad (Ch 3), so flip the box frame by pi about x.
inline Isometry3d topDownTcp(const Isometry3d & T_frame_box, double size_z) {
  return T_frame_box * trans(0.0, 0.0, size_z / 2) * rotX(M_PI);
}

}  // namespace cell_planning
```

```cpp
// cell_planning/test/test_geometry.cpp
#include <gtest/gtest.h>
#include <cell_planning/geometry.hpp>

using namespace cell_planning;

TEST(Geometry, TopDownTcpPointsDown) {
  const Isometry3d T_box = trans(0.2, 0.1, 0.075) * rotZ(0.5);
  const Isometry3d T_tcp = topDownTcp(T_box, 0.15);
  EXPECT_TRUE(T_tcp.translation().isApprox(Eigen::Vector3d(0.2, 0.1, 0.15)));     // at the top face
  EXPECT_TRUE(T_tcp.linear().col(2).isApprox(Eigen::Vector3d(0, 0, -1)));         // z axis points down
  EXPECT_TRUE(T_tcp.linear().col(0).isApprox(T_box.linear().col(0)));             // x follows the box yaw
}

TEST(Geometry, PoseRoundTrip) {                                                      // Ch 4 checkpoint
  const Isometry3d T = trans(0.3, -0.2, 0.5) * rotX(0.3) * rotZ(1.2);
  EXPECT_TRUE(matFromPose(poseFromMat(T)).isApprox(T, 1e-9));
}
```

## Listening and broadcasting in a node: `ros2_basics/src/tf_demo.cpp`

```cpp
#include <algorithm>
#include <chrono>
#include <rclcpp/rclcpp.hpp>
#include <tf2_ros/buffer.h>
#include <tf2_ros/transform_listener.h>
#include <tf2_ros/transform_broadcaster.h>
#include <tf2_ros/static_transform_broadcaster.h>
#include <geometry_msgs/msg/transform_stamped.hpp>

class TfDemo : public rclcpp::Node {
public:
  TfDemo() : Node("tf_demo"), buf_(get_clock()), listener_(buf_), static_br_(this), br_(this) {
    geometry_msgs::msg::TransformStamped t;                 // a box that never moves: static
    t.header.stamp = now();
    t.header.frame_id = "pallet_frame";
    t.child_frame_id = "box_1";
    t.transform.translation.x = -0.25; t.transform.translation.y = 0.15; t.transform.translation.z = 0.075;
    t.transform.rotation.w = 1.0;
    static_br_.sendTransform(t);

    belt_timer_ = create_wall_timer(std::chrono::milliseconds(50), [this]() { beltTick(); });   // dynamic, 20 Hz
    report_timer_ = create_wall_timer(std::chrono::seconds(1), [this]() { report(); });
  }

private:
  void beltTick() {
    y_ = std::min(y_ + 0.01, 0.0);                          // 0.2 m/s, stops at the photo-eye
    geometry_msgs::msg::TransformStamped t;
    t.header.stamp = now();
    t.header.frame_id = "conveyor_frame";
    t.child_frame_id = "box_belt";
    t.transform.translation.y = y_; t.transform.translation.z = 0.075;
    t.transform.rotation.w = 1.0;
    br_.sendTransform(t);
  }
  void report() {
    try {
      const auto tf = buf_.lookupTransform("pallet_frame", "tcp", tf2::TimePointZero, tf2::durationFromSec(0.5));
      const auto & p = tf.transform.translation;
      RCLCPP_INFO(get_logger(), "tcp in pallet_frame: x=%.3f y=%.3f z=%.3f", p.x, p.y, p.z);
    } catch (const tf2::TransformException & e) {
      RCLCPP_WARN(get_logger(), "%s", e.what());
    }
  }
  tf2_ros::Buffer buf_;                         // filled from /tf and /tf_static by the listener
  tf2_ros::TransformListener listener_;         // owns a spinning thread of its own
  tf2_ros::StaticTransformBroadcaster static_br_;
  tf2_ros::TransformBroadcaster br_;
  rclcpp::TimerBase::SharedPtr belt_timer_, report_timer_;
  double y_{-0.7};
};

int main(int argc, char ** argv) {
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<TfDemo>());
  rclcpp::shutdown();
}
```

Add to `ros2_basics/CMakeLists.txt`: `find_package(tf2_ros REQUIRED)`, `find_package(geometry_msgs REQUIRED)`, `add_executable(tf_demo src/tf_demo.cpp)`, `ament_target_dependencies(tf_demo rclcpp tf2_ros geometry_msgs)`, and `tf_demo` in the `install(TARGETS …)` list; `<depend>tf2_ros</depend>` and `<depend>geometry_msgs</depend>` in `package.xml`.

Transforming a message instead of a matrix: `tf2::doTransform(pose_in, pose_out, buf_.lookupTransform("world", pose_in.header.frame_id, tf2::TimePointZero))` from `tf2_geometry_msgs/tf2_geometry_msgs.hpp`.
