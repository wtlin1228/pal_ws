Ch 0 — VM and ROS 2 setup (week 1, days 1–2)

Goal: a snapshot-able Ubuntu 24.04 VM with ROS 2 Jazzy, MoveIt 2, the UR description packages and a working RViz. Take a VM snapshot at the end; you will want to roll back more than once.

VM sizing

Setting UTM on Apple Silicon (M-series) KVM on Debian
Backend Virtualize (not Emulate) with the QEMU backend: leave “Use Apple Virtualization” unchecked, since UTM snapshots work only with QEMU; Ubuntu 24.04 Server arm64 ISO QEMU/KVM, Ubuntu 24.04 Server amd64 ISO
CPU / RAM 6 cores, 10–16 GB 6 cores, 12–16 GB
Disk 64 GB (MoveIt + Gazebo + bags grow fast) 64 GB
Display Leave hardware OpenGL acceleration off at first (software rendering is enough for this scene; try it later from a snapshot); install ubuntu-desktop-minimal after the server install virtio-gpu with 3D acceleration in virt-manager
Network Shared (NAT) NAT

Use the Server ISO plus a minimal desktop: fewer background services, lighter RViz. Clipboard and folder sharing: UTM supports SPICE agent (spice-vdagent) and virtiofs mounts; turn both on so you can edit code in your Mac editor if you prefer.

Install ROS 2 Jazzy

sudo apt update && sudo apt install -y software-properties-common curl locales
sudo locale-gen en_US en_US.UTF-8 && sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
sudo add-apt-repository -y universe

# ros-apt-source installs the repo and key for your Ubuntu release
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F\" '{print $4}')
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo $VERSION_CODENAME)_all.deb"
sudo apt install -y /tmp/ros2-apt-source.deb

sudo apt update && sudo apt install -y ros-jazzy-desktop ros-dev-tools \
  ros-jazzy-moveit ros-jazzy-moveit-setup-assistant \
  ros-jazzy-ros2-control ros-jazzy-ros2-controllers \
  ros-jazzy-ur ros-jazzy-vision-msgs ros-jazzy-tf2-tools \
  python3-colcon-common-extensions python3-rosdep python3-numpy python3-scipy python3-opencv python3-matplotlib \
  libopencv-dev libeigen3-dev

sudo rosdep init; rosdep update
echo 'source /opt/ros/jazzy/setup.bash' >> ~/.bashrc
echo 'export ROS_DOMAIN_ID=7' >> ~/.bashrc   # keep your traffic separate from other machines on the LAN
source ~/.bashrc

apt refuses the whole command if a single package name is unknown, and some packages lag on arm64: drop that package and rerun. If ros-jazzy-ur is missing, install ros-jazzy-ur-description only; this tutorial never needs the real driver.

Smoke test

# terminal 1
ros2 run demo_nodes_cpp talker
# terminal 2
ros2 run demo_nodes_py listener
# terminal 3: the UR10e model in RViz
ros2 launch ur_description view_ur.launch.py ur_type:=ur10e

You should see Hello World: N flowing and a UR10e you can pose with the joint sliders.

RViz in a VM: known fixes

# black window, OpenGL errors, or RViz crashes on start → force software rendering
export LIBGL_ALWAYS_SOFTWARE=1
# Qt scaling looks wrong on a Retina display
export QT_SCALE_FACTOR=1.5

Put the lines you need in ~/.bashrc. Software rendering is fine for this tutorial: the scene has fewer than 50 objects.

Workspace and tooling

mkdir -p ~/pal_ws/src && cd ~/pal_ws
colcon build            # builds nothing yet but creates install/
echo 'source ~/pal_ws/install/setup.bash' >> ~/.bashrc
sudo apt install -y git tmux ros-jazzy-rqt-graph ros-jazzy-rqt-tf-tree

tmux matters: most chapters need 3–5 terminals. A ~/.tmux.conf with set -g mouse on is enough.

Snapshot the VM now (UTM: right-click the VM → Snapshots; virt-manager: View → Snapshots).
