Ch 3 — Describe the cell: URDF/Xacro, UR10e + suction gripper, RViz (week 2)

Goal: one Xacro file that describes the whole cell (robot, gripper, pedestal, pallet, conveyor, camera) and a launch file that shows it in RViz with joint sliders. MoveIt, TF and the mock camera all read this file.

Concepts in one minute

  • URDF is a tree: links (geometry: visual, collision, inertial) connected by joints (fixed, revolute, prismatic). One root, no loops.
  • Xacro adds properties, math, macros and includes on top of URDF. xacro file.xacro outputs plain URDF.
  • Collision geometry should be simple (boxes, cylinders): MoveIt checks it thousands of times per plan. Visual geometry can be meshes.
  • A frame with no geometry (tcp, pallet_frame) is just an empty link joined with a fixed joint; it exists so you can name a pose.
world
├── pedestal
├── base_link (UR10e) → shoulder → upper_arm → forearm → wrist_1 → wrist_2 → wrist_3 → flange → tool0
│                                                                                   └── gripper_body → suction_pad → tcp
├── pallet_frame → pallet
├── conveyor_frame → conveyor
└── camera_link → camera_optical_frame

urdf/suction_gripper.xacro

<?xml version="1.0"?>
<robot xmlns:xacro="http://wiki.ros.org/xacro">
  <!-- A foam suction gripper: body + pad + a TCP frame at the pad face. z of tool0 points out of the flange. -->
  <xacro:macro name="suction_gripper" params="parent">
    <link name="gripper_body">
      <visual><origin xyz="0 0 0.05"/><geometry><cylinder radius="0.04" length="0.10"/></geometry>
        <material name="dark"><color rgba="0.25 0.25 0.25 1"/></material></visual>
      <collision><origin xyz="0 0 0.05"/><geometry><cylinder radius="0.04" length="0.10"/></geometry></collision>
      <inertial><mass value="0.8"/><origin xyz="0 0 0.05"/><inertia ixx="0.001" iyy="0.001" izz="0.001" ixy="0" ixz="0" iyz="0"/></inertial>
    </link>
    <joint name="${parent}-gripper_body" type="fixed">
      <parent link="${parent}"/><child link="gripper_body"/><origin xyz="0 0 0" rpy="0 0 0"/>
    </joint>

    <link name="suction_pad">
      <visual><geometry><box size="0.25 0.15 0.02"/></geometry>
        <material name="orange"><color rgba="0.9 0.38 0.15 1"/></material></visual>
      <collision><geometry><box size="0.25 0.15 0.02"/></geometry></collision>
      <inertial><mass value="0.4"/><inertia ixx="0.001" iyy="0.001" izz="0.001" ixy="0" ixz="0" iyz="0"/></inertial>
    </link>
    <joint name="gripper_body-suction_pad" type="fixed">
      <parent link="gripper_body"/><child link="suction_pad"/><origin xyz="0 0 0.11"/>
    </joint>

    <!-- TCP: where the pad touches the box. All pick/place poses are expressed here. -->
    <link name="tcp"/>
    <joint name="suction_pad-tcp" type="fixed">
      <parent link="suction_pad"/><child link="tcp"/><origin xyz="0 0 0.01"/>
    </joint>
  </xacro:macro>
</robot>

urdf/cell.urdf.xacro

<?xml version="1.0"?>
<robot name="cell" xmlns:xacro="http://wiki.ros.org/xacro">
  <xacro:arg name="ur_type" default="ur10e"/>
  <xacro:include filename="$(find ur_description)/urdf/ur_macro.xacro"/>
  <xacro:include filename="$(find cell_description)/urdf/suction_gripper.xacro"/>

  <!-- cell dimensions [m]; keep them here, every chapter reads them -->
  <xacro:property name="pedestal_h" value="0.60"/>
  <xacro:property name="pallet_x"   value="0.80"/>
  <xacro:property name="pallet_y"   value="0.60"/>
  <xacro:property name="pallet_h"   value="0.144"/>
  <xacro:property name="pallet_pos" value="0 0.75"/>
  <xacro:property name="conv_top"   value="0.70"/>
  <xacro:property name="cam_h"      value="2.20"/>

  <xacro:macro name="fixed_box" params="name parent xyz size color">
    <link name="${name}">
      <visual><geometry><box size="${size}"/></geometry><material name="${name}_m"><color rgba="${color}"/></material></visual>
      <collision><geometry><box size="${size}"/></geometry></collision>
      <inertial><mass value="10"/><inertia ixx="1" iyy="1" izz="1" ixy="0" ixz="0" iyz="0"/></inertial>
    </link>
    <joint name="${parent}-${name}" type="fixed"><parent link="${parent}"/><child link="${name}"/><origin xyz="${xyz}"/></joint>
  </xacro:macro>

  <link name="world"/>

  <xacro:fixed_box name="pedestal" parent="world" xyz="0 0 ${pedestal_h/2}" size="0.3 0.3 ${pedestal_h}" color="0.4 0.4 0.45 1"/>

  <!-- UR10e: geometry only in Jazzy. If your ur_macro adds a ros2_control tag, pass generate_ros2_control_tag="false". -->
  <xacro:ur_robot
    name="ur10e" tf_prefix="" parent="world"
    joint_limits_parameters_file="$(find ur_description)/config/$(arg ur_type)/joint_limits.yaml"
    kinematics_parameters_file="$(find ur_description)/config/$(arg ur_type)/default_kinematics.yaml"
    physical_parameters_file="$(find ur_description)/config/$(arg ur_type)/physical_parameters.yaml"
    visual_parameters_file="$(find ur_description)/config/$(arg ur_type)/visual_parameters.yaml"
    safety_limits="true" safety_pos_margin="0.15" safety_k_position="20" force_abs_paths="false">
    <origin xyz="0 0 ${pedestal_h}" rpy="0 0 0"/>
  </xacro:ur_robot>

  <xacro:suction_gripper parent="tool0"/>

  <!-- pallet_frame sits on the TOP surface center: box z positions are heights above the deck -->
  <link name="pallet_frame"/>
  <joint name="world-pallet_frame" type="fixed"><parent link="world"/><child link="pallet_frame"/><origin xyz="${pallet_pos} ${pallet_h}"/></joint>
  <xacro:fixed_box name="pallet" parent="pallet_frame" xyz="0 0 ${-pallet_h/2}" size="${pallet_x} ${pallet_y} ${pallet_h}" color="0.75 0.6 0.35 1"/>

  <link name="conveyor_frame"/>
  <joint name="world-conveyor_frame" type="fixed"><parent link="world"/><child link="conveyor_frame"/><origin xyz="-0.9 0 ${conv_top}"/></joint>
  <xacro:fixed_box name="conveyor" parent="conveyor_frame" xyz="0 0 ${-conv_top/2}" size="0.5 1.5 ${conv_top}" color="0.3 0.3 0.3 1"/>

  <!-- camera: optical frame convention is z forward (viewing), x right, y down → roll by pi to look at the floor -->
  <link name="camera_link"><visual><geometry><box size="0.1 0.05 0.04"/></geometry></visual></link>
  <joint name="world-camera_link" type="fixed"><parent link="world"/><child link="camera_link"/><origin xyz="${pallet_pos} ${cam_h}"/></joint>
  <link name="camera_optical_frame"/>
  <joint name="camera_link-optical" type="fixed"><parent link="camera_link"/><child link="camera_optical_frame"/><origin rpy="${pi} 0 0"/></joint>
</robot>

Launch and RViz

# cell_description/launch/view_cell.launch.py
from launch import LaunchDescription
from launch.substitutions import Command, FindExecutable, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.parameter_descriptions import ParameterValue
from launch_ros.substitutions import FindPackageShare

def generate_launch_description():
    pkg = FindPackageShare('cell_description')
    xacro_file = PathJoinSubstitution([pkg, 'urdf', 'cell.urdf.xacro'])
    robot_description = ParameterValue(Command([FindExecutable(name='xacro'), ' ', xacro_file]), value_type=str)
    return LaunchDescription([
        Node(package='robot_state_publisher', executable='robot_state_publisher',
             parameters=[{'robot_description': robot_description}]),
        Node(package='joint_state_publisher_gui', executable='joint_state_publisher_gui'),
        Node(package='rviz2', executable='rviz2',
             arguments=['-d', PathJoinSubstitution([pkg, 'rviz', 'cell.rviz'])]),
    ])

install(DIRECTORY urdf launch rviz DESTINATION share/${PROJECT_NAME})

What robot_state_publisher does

It reads the URDF, publishes fixed transforms once (/tf_static) and, for every JointState message on /joint_states, publishes the moving transforms on /tf. This is the bridge from "joint angles" to "where is the TCP". The slider GUI publishes /joint_states; in Ch 5 ros2_control takes over that role.

Real cell: the URDF of a production cell comes from CAD and a calibration step; the kinematics YAML of a UR is read from the controller because every unit differs slightly. Primitives for pallets and conveyors are normal practice.
