# Ch 16 — Robustness: errors, recovery, rosbag replay, tests (week 11)

Goal: make the cell survive the failures a real one sees every shift, inject those failures into the mocks on purpose, replay recorded sensor data as mock input, and test the logic without a robot.

## Failure catalogue

| Failure | Where it shows | Response |
| --- | --- | --- |
| No vacuum at grasp | `PickPlace` result `no vacuum` | retreat, re-capture, retry with the other grasp candidate, then skip the box |
| Vacuum lost in transit | `/gripper/vacuum` drops while carrying | stop, detach the scene object, re-capture: the box is somewhere new |
| No plan / no IK | `approach: no plan` | retry with approach distance +5 cm, then a different candidate; log the pose |
| Execution aborted by the controller | `ExecuteTrajectory` fails | re-plan from the current state; never resend the old trajectory |
| No detections but the pallet is not empty | `DONE` too early | re-capture once; compare with the belief (Ch 15); alarm |
| Double pick | two boxes move in `world/boxes` | risk threshold (Ch 11); a weight or height check after lift on a real cell |
| Stale scene after a crash | planner refuses everything | clear the scene and detach all objects at startup |
| Service never answers | hangs | every call gets a timeout; a timeout is a failure like any other |

## Four changes that cover most of it

1. **Startup cleanup** in `PickPlaceServer::init()`: detach whatever a crashed run left on the gripper; `Executive::execute` already starts with `scene_.clear()`.
2. **Vacuum watchdog**: subscribe to `/gripper/vacuum` in the server and check it after LIFT and after TRANSIT:

```cpp
    // init(): no stale attachment survives a crash
    for (const auto & [id, obj] : scene_.getAttachedObjects()) robot_->mg().detachObject(id);
    // members and init(): the vacuum switch
    std::atomic<bool> vacuum_{false};
    vacuum_sub_ = create_subscription<std_msgs::msg::Bool>("gripper/vacuum", 10,
      [this](std_msgs::msg::Bool::ConstSharedPtr m) { vacuum_ = m->data; });
    // execute(), after each carrying stage:
    if (!vacuum_) {
      robot_->mg().detachObject(g->box_id);
      scene_.removeCollisionObjects({g->box_id});
      return fail("vacuum lost");                           // not 'still holding': the box is gone
    }
```

3. **Variation on retry** in `Executive`: keep a `retries_` member that RECOVER increments and a success resets; in `planPick`, on an odd retry take the other grasp candidate (`graspCandidates(T_box, size)[1]`) if its `doublePickRisk` is acceptable, and raise the approach: `g.approach_distance = 0.15 + 0.05 * retries_;`.
4. **Timeouts everywhere**: every wait in the executive already carries one (`capture`, `callTrigger`, `runPick`, `waitFrame` are all `wait_for` with a deadline). A timeout is a failure like any other and routes to RECOVER; never block on a bare `future.get()` in the job thread.

## Fault injection in the mocks

```python
# mock_gripper.py additions: parameters you flip at runtime with `ros2 param set`
        self.declare_parameter('fail_every_n', 0)          # 0 = never; 4 = every 4th grip finds no vacuum
        self.declare_parameter('drop_after_s', 0.0)        # > 0: the seal fails this long after a grip
        self.grips, self.grip_time = 0, None
        self.create_timer(0.1, self.watch_seal)

    def handle(self, req, res):                            # at the top of the existing handler
        if req.on:
            self.grips += 1
            n = self.get_parameter('fail_every_n').value
            if n and self.grips % n == 0:
                res.success, res.message = False, 'no vacuum (injected)'; self.vacuum = False; return res
            self.grip_time = time.monotonic()
        # ... existing code ...

    def watch_seal(self):
        t = self.get_parameter('drop_after_s').value
        if self.vacuum and t > 0 and time.monotonic() - self.grip_time > t:
            self.world.call(SetBool.Request(data=False)); self.vacuum = False
            self.get_logger().warn('seal lost (injected)')
```

```bash
ros2 param set /mock_gripper fail_every_n 3
ros2 param set /mock_gripper drop_after_s 2.0
ros2 action send_goal /run_job cell_interfaces/action/RunJob "{mode: depalletize, strategy: single_sku}" --feedback
```

A dropped box lands wherever it was (`settle()` in the world model), usually on the floor, with `location: unknown`; the next capture no longer sees it, so the job continues with the rest of the pallet.

## rosbag: recorded data as mock input

```bash
# record while a job runs
ros2 bag record -o depal_run /camera/points /detections /tf /tf_static /photo_eye /gripper/vacuum /joint_states
# later, develop the detector against the recording, no twin running
ros2 run cell_perception box_detector
ros2 bag play depal_run --topics /camera/points /tf /tf_static --loop
ros2 topic echo /detections --once
```

The detector looks transforms up at `tf2::TimePointZero` (latest), so old stamps in the bag are fine. For nodes that need timestamps to agree, play with `--clock` and start them with `use_sim_time:=true`. A bag of a real camera becomes a regression test for your vision pipeline: record once, replay forever.

## Tests that run in CI

- Pure logic (`cell_planning`, `cell_perception`): GoogleTest through `colcon test`, already a dozen tests; add one per bug you fix.
- Node integration with `launch_testing` (Python, and the standard for C++ nodes too): start `world_model`, `mock_camera` and `box_detector`, spawn a scene, assert six detections within 10 s.

```python
# cell_perception/test/test_detector_launch.py
import time, unittest, rclpy, launch, launch_testing, launch_testing.actions
from launch.actions import ExecuteProcess, IncludeLaunchDescription, TimerAction
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare
from vision_msgs.msg import Detection3DArray

def generate_test_description():
    rsp = IncludeLaunchDescription(PythonLaunchDescriptionSource(
        [FindPackageShare('cell_description'), '/launch/rsp_only.launch.py']))
    nodes = [Node(package='cell_sim', executable='world_model'),
             Node(package='cell_sim', executable='mock_camera', parameters=[{'continuous_hz': 2.0}]),
             Node(package='cell_perception', executable='box_detector')]
    spawn = ExecuteProcess(cmd=['ros2', 'run', 'cell_sim', 'spawn_scene', '--layers', '1'])
    return launch.LaunchDescription([rsp, *nodes, TimerAction(period=3.0, actions=[spawn]),
                                     launch_testing.actions.ReadyToTest()]), {}

class TestDetector(unittest.TestCase):
    def test_six_boxes(self):
        rclpy.init(); node = rclpy.create_node('probe'); got = []
        node.create_subscription(Detection3DArray, 'detections', got.append, 10)
        t0 = time.time()
        while time.time() - t0 < 15 and not any(len(m.detections) == 6 for m in got):
            rclpy.spin_once(node, timeout_sec=0.2)
        rclpy.shutdown()
        self.assertTrue(any(len(m.detections) == 6 for m in got))
```

Run it with `launch_test src/cell_perception/test/test_detector_launch.py` (`rsp_only.launch.py` is `view_cell.launch.py` without the slider GUI and RViz, so it runs headless).

Real cell: the same catalogue exists with more rows (safety stops, PLC faults, pallet not present, label unreadable). The important design decision is the same: every failure returns to a known state (robot at a safe pose, scene consistent, belief re-measured) before anything is retried.
