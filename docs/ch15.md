# Ch 15 — Mixed SKU: online placement and pick ordering (week 10)

Goal: palletize boxes of three sizes arriving in unknown order, one decision at a time, with a height-map placement heuristic; and depalletize mixed stacks by picking the highest safe box. The height map you built for detection now drives placement.

## The problem

| | Single SKU (Ch 12) | Mixed SKU |
| --- | --- | --- |
| Known in advance | box size, count | only the SKU table; the sequence arrives box by box |
| Plan | pattern file, computed once | online: place each box where the surface allows |
| Quality drivers | interlock, utilization | support (stability), flat surface, low center of mass, utilization |
| Failure mode | none if the pattern is right | a box with 50 % support tips; a tall column blocks later picks |

Online mixed palletizing is a heuristic search. The one here is the classic "deepest bottom-left with support": among all candidate positions, take the lowest resting height, then the best support, then the far-left corner. Real systems add many more terms (seal lines, fragility, delivery order, overhang rules); the structure stays the same.

## `cell_planning/include/cell_planning/mixed.hpp`

```cpp
#pragma once
#include <algorithm>
#include <cmath>
#include <optional>
#include <tuple>
#include <utility>
#include <Eigen/Core>
#include <cell_planning/palletizer.hpp>

namespace cell_planning {

/// Belief of the pallet surface in pallet_frame, 1 cm cells: the same structure the detector builds (Ch 10).
class HeightMap {
public:
  struct Window { int x0, y0, x1, y1; };                           // cells [x0, x1) x [y0, y1)

  explicit HeightMap(double cell = 0.01, double gap = 0.01)
  : c_(cell), gap_(gap), nx_(std::lround(PALLET[0] / cell)), ny_(std::lround(PALLET[1] / cell)),
    h_(Eigen::MatrixXd::Zero(ny_, nx_)), halo_(Eigen::MatrixXd::Zero(ny_, nx_)) {}

  /// Cells covering a w x d footprint centered at (x, y). Off the deck: nothing, or clipped if clip is set.
  std::optional<Window> window(double x, double y, double w, double d, bool clip = false) const {
    int x0 = std::lround((x - w / 2 + PALLET[0] / 2) / c_), x1 = x0 + std::lround(w / c_);
    int y0 = std::lround((y - d / 2 + PALLET[1] / 2) / c_), y1 = y0 + std::lround(d / c_);
    if (x0 < 0 || y0 < 0 || x1 > nx_ || y1 > ny_) {
      if (!clip) return std::nullopt;
      x0 = std::max(x0, 0); y0 = std::max(y0, 0); x1 = std::min(x1, nx_); y1 = std::min(y1, ny_);
    }
    return Window{x0, y0, x1, y1};
  }

  /// Height the box would rest at, and the fraction of its footprint touching that height.
  /// The halo counts for the rest height but never as support: a box touching a neighbor is unsupported.
  std::pair<double, double> rest(const Window & w, double tol = 0.005) const {
    const auto H = h_.block(w.y0, w.x0, w.y1 - w.y0, w.x1 - w.x0);
    const double z = std::max(H.maxCoeff(), halo_.block(w.y0, w.x0, w.y1 - w.y0, w.x1 - w.x0).maxCoeff());
    const double support = (H.array() >= z - tol).cast<double>().mean();
    return {z, support};
  }

  void place(double x, double y, double w, double d, double z_top) {
    const Window win = *window(x, y, w, d);
    h_.block(win.y0, win.x0, win.y1 - win.y0, win.x1 - win.x0).setConstant(z_top);
    const Window g = *window(x, y, w + 2 * gap_, d + 2 * gap_, true);   // keep-out ring around every placed box
    auto halo = halo_.block(g.y0, g.x0, g.y1 - g.y0, g.x1 - g.x0);
    halo = halo.cwiseMax(z_top);
  }

  const Eigen::MatrixXd & heights() const { return h_; }

private:
  double c_, gap_;
  int nx_, ny_;
  Eigen::MatrixXd h_, halo_;
};

struct Placement { double x, y, yaw, z; };

/// Lowest rest height, then most support, then the far-left corner.
inline std::optional<Placement> bestPlacement(const HeightMap & hm, const BoxSize & size, double step = 0.02,
                                              double min_support = 0.7, double max_height = 0.6) {
  std::optional<Placement> best;
  std::tuple<double, double, double, double> best_key;
  for (double yaw : {0.0, M_PI / 2}) {
    const auto [w, d] = footprint(size, yaw);
    for (double x = -PALLET[0] / 2 + w / 2; x <= PALLET[0] / 2 - w / 2 + 1e-9; x += step)
      for (double y = -PALLET[1] / 2 + d / 2; y <= PALLET[1] / 2 - d / 2 + 1e-9; y += step) {
        const auto win = hm.window(x, y, w, d);
        if (!win) continue;
        const auto [z, support] = hm.rest(*win);
        if (support < min_support || z + size.z > max_height) continue;
        const auto key = std::make_tuple(std::round(z * 1000) / 1000, -std::round(support * 100) / 100,
                                         -std::round(y * 1000) / 1000, std::round(x * 1000) / 1000);   // low, supported, far side, left
        if (!best || key < best_key) { best = Placement{x, y, yaw, z}; best_key = key; }
      }
  }
  return best;
}

/// Online placement, one box at a time; sizes known on arrival. Same Plan interface as SingleSkuPlan.
class MixedPlan : public Plan {
public:
  explicit MixedPlan(double max_height = 0.6) : max_height_(max_height) {}

  std::optional<Isometry3d> target(const BoxSize & size) override {
    const auto p = bestPlacement(hm_, size, 0.02, 0.7, max_height_);
    if (!p) return std::nullopt;
    pending_ = {*p, size};
    return trans(p->x, p->y, p->z + size.z / 2) * rotZ(p->yaw);
  }
  void confirm() override {
    const auto & [p, size] = pending_;
    const auto [w, d] = footprint(size, p.yaw);
    hm_.place(p.x, p.y, w, d, p.z + size.z);
    placed_.emplace_back(trans(p.x, p.y, p.z + size.z / 2) * rotZ(p.yaw), size);
  }
  const Placed & placed() const override { return placed_; }
  const HeightMap & heightMap() const { return hm_; }

private:
  HeightMap hm_;
  double max_height_;
  std::pair<Placement, BoxSize> pending_{};
  Placed placed_;
};

}  // namespace cell_planning
```

On the sequence `ABCABCABCABC` this places 8 boxes with no overlaps, 2 cm gaps between same-level neighbors and every box at least 70 % supported, in about 0.1 s per decision; `AAAAAAAAAAAA` places 12 (two full layers). The halo is what keeps the gaps the detector needs (Ch 10).

TEST(Mixed, SameLevelNeighborsKeepAGap) {
  MixedPlan plan;
  for (int i = 0; i < 6; ++i) { ASSERT_TRUE(plan.target(SKU_A)); plan.confirm(); }
  const auto & P = plan.placed();
  for (std::size_t i = 0; i < P.size(); ++i)
    for (std::size_t j = i + 1; j < P.size(); ++j) {
      const auto & [Ta, a] = P[i]; const auto & [Tb, b] = P[j];
      if (std::abs(Ta.translation().z() - Tb.translation().z()) > 1e-6) continue;
      const auto [wa, da] = footprint(a, yawOf(Ta)); const auto [wb, db] = footprint(b, yawOf(Tb));
      const double gx = std::abs(Ta.translation().x() - Tb.translation().x()) - (wa + wb) / 2;
      const double gy = std::abs(Ta.translation().y() - Tb.translation().y()) - (da + db) / 2;
      EXPECT_GE(std::max(gx, gy), 0.02 - 1e-6);

## Executive changes

1. The plan is chosen by strategy at the start of `execute`: `if (req.strategy == "mixed") plan_ = std::make_unique<MixedPlan>(); else plan_ = std::make_unique<SingleSkuPlan>(3);`. `planPlace` needs no change: it already asks the plan with the box size.
2. Depalletizing picks the **highest safe** box instead of the highest box:

```cpp
  /// Highest SAFE box first; SKU height overrides the detector's; skip grasps that risk a double pick.
  std::optional<PickPlace::Goal> planPick(const Dets & dets) {
    auto top = [](const vision_msgs::msg::Detection3D & d) { return d.bbox.center.position.z + d.bbox.size.z / 2; };
    auto sizeOf = [](const vision_msgs::msg::Detection3D & o) { return matchSku(o.bbox.size.x, o.bbox.size.y).second; };
    std::vector<const vision_msgs::msg::Detection3D *> order;
    for (const auto & d : dets.detections) order.push_back(&d);
    std::sort(order.begin(), order.end(), [&](const auto * a, const auto * b) { return top(*a) > top(*b); });   // highest top first
    for (const auto * dp : order) {
      const auto & d = *dp;
      const auto [sku, size] = matchSku(d.bbox.size.x, d.bbox.size.y);
      Isometry3d T_box = matFromPose(d.bbox.center);
      T_box.translation().z() = top(d) - size.z / 2;
      std::vector<Neighbor> others;
      for (const auto & o : dets.detections) if (o.id != d.id) others.push_back({matFromPose(o.bbox.center), sizeOf(o)});
      const auto [risk, T_pick] = bestGrasp(T_box, size, others);
      if (risk > 0.1) { RCLCPP_WARN(get_logger(), "%s: double-pick risk %.2f, trying the next box", d.id.c_str(), risk); continue; }
      scene_.sync(dets, sizeOf);
      const Isometry3d T_wp = tf2::transformToEigen(buf_.lookupTransform("world", "pallet_frame", tf2::TimePointZero, tf2::durationFromSec(1.0)));
      const Isometry3d T_place = CONVEYOR_TOP * trans(0.0, 0.0, size.z) * rotX(M_PI);   // TCP at box-top height over the eye
      PickPlace::Goal g;
      g.box_id = d.id;
      g.pick_pose = stamped(T_wp * T_pick);
      g.place_pose = stamped(T_place);
      g.box_size.x = size.x; g.box_size.y = size.y; g.box_size.z = size.z;
      RCLCPP_INFO(get_logger(), "%s: sku '%s' risk %.2f", d.id.c_str(), sku.c_str(), risk);
      return g;
    }
    return std::nullopt;                                                  // nothing safe: DONE, a person looks
  }
```

## Verify the belief against the camera

After palletizing, trigger a capture and compare the detector's height map with `plan->heightMap().heights()`: publish the belief as a `nav_msgs/OccupancyGrid`-style debug image, or log the largest absolute difference between the two grids in a small node. A real system does exactly this: it re-measures the pallet after each place and corrects its belief when a box shifted.

Real cell: commercial mixed-case palletizers run a much richer scorer and often look several boxes ahead using a buffer conveyor that lets them reorder. The height map, support ratio and keep-out halo are the same primitives.

## Go deeper

- [Wang and Hauser, ICRA 2019](https://motion.cs.illinois.edu/papers/ICRA2019-Wang-BinPacking.pdf): the heightmap-minimization heuristic this chapter simplifies, with explicit stability and robot-packability constraints (can the gripper reach the placement without hitting what is already there?). Adding that reachability check to `bestPlacement` is the natural next step.
- [Gao et al., 2025](https://web3.arxiv.org/pdf/2507.09123): online 3D bin packing with a fast stability validation and rearrangement planning; the stability check is what `min_support` approximates.
- [RoboBPP](https://arxiv.org/pdf/2512.04415): an open benchmark with a physics simulator, three real industrial box datasets and a leaderboard. Feed one of its box sequences through `MixedPlan` instead of `ABCABC` to see how the heuristic behaves on real size distributions, and compare your utilization with the published baselines.
